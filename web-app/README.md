# Lifestreak Web App

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Routes

- `/` - Heatmap (default, rolling 90-day)
- `/logger` - Habit logger
- `/friends` - Friends dashboard
- `/settings` - Settings and theme toggle

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui components
